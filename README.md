# Mushroom-Classification-Dataset

This repository contains a mushroom image classification dataset used in our research.

The dataset includes 12 mushroom categories and is divided into training, validation, and test sets at a ratio of 6:2:2.

## Dataset Structure

```text
Mushroom-Classification-Dataset/
├── train/
├── val/
├── test/
└── README.md
```

Each subset contains images organized by mushroom category.
